# المرحلة B — المرفقات وخزنة الإثباتات

الحالة: **مخططة بعد اكتمال «طالبني»**.

المرجع: قسم «المرفقات وخزنة الإثباتات» في `WASL_MASTER_PROJECT_PROMPT.md`.

## الهدف

إرفاق صورة أو PDF أو ملف بالدين، وربطه اختياريًا بعملية محددة، مع تخزين محلي خاص بالتطبيق وسجل metadata يتيح التحقق والنسخ الاحتياطي والاستعادة بأمان.

## ثوابت الأمان

- لا تخزين داخل مسار عام مكشوف كمرجع أساسي.
- لا حفظ URI مؤقت باعتباره ضمان وصول دائم دون نسخ المحتوى إلى خزنة التطبيق.
- اسم الملف المقدم من المستخدم لا يستخدم كمسار مباشر.
- SHA-256 لكل ملف محفوظ.
- حجم ونوع MIME ووقت الإضافة محفوظة.
- فتح/مشاركة من خلال FileProvider وعند فعل صريح فقط.
- حماية من path traversal عند Backup/Restore.
- فقد الملف أو اختلاف SHA يظهر كحالة تلف؛ لا يتم تمثيله كمرفق سليم.
- المرفقات سجل شخصي توثيقي وليست ضمانًا قانونيًا تلقائيًا.

## نموذج البيانات المتوقع

- `id`
- `debt_id`
- `ledger_entry_id` اختياري
- `display_name`
- `mime_type`
- `size_bytes`
- `relative_path`
- `sha256`
- `created_at`
- `note` اختياري
- حالة سلامة مشتقة عند القراءة، لا تخزن كحقيقة مالية.

## الاختبارات قبل الاكتمال

- إضافة صورة وPDF وملف عام.
- ربط بالدين وربط بعملية محددة.
- رفض مسارات غير آمنة.
- اكتشاف hash mismatch والفقد.
- فتح ومشاركة فقط عبر URI آمن.
- Backup/Restore round-trip للملف والmetadata.
- استعادة نسخة بها ملف تالف تفشل بأمان أو تعزل العنصر حسب سياسة الاستعادة المثبتة.
- Room migration + instrumentation + lint + build.
