# مراجعة الاستكمال — صيانة 0.1.1

طلب الدمج: https://github.com/ahmed9461/Wasl/pull/14

## عيوب إضافية أعيد إنتاجها

أثناء المراجعة الثانية، قبل تعديلها، أعادت عينات Kotlin المحلية النتائج التالية مع ready=true:

- `سلفت خالد 5 آلاف سعودي` → 5 SAR بدل إدراك عدم دعم المبلغ المركب.
- `سلفت خالد خمسة آلاف وخمسمئة سعودي` → 5000 SAR، مع إسقاط الجزء الإضافي.
- `سلفت خالد 100 سعودي أو يمني` → اختيرت SAR دون طلب تحديد العملة.
- `سلفت sara 100` → استنتجت SAR من بداية اسم الشخص دون وجود عملة صريحة.

صححت حدود أسماء العملات واشتراط عملة واحدة، وحددت صيغة المبلغ المقبولة: رمز عددي كامل يليه اسم العملة مباشرة، أو عبارة الآلاف اللفظية البسيطة المدعومة كاملة قبل العملة. المدخلات المركبة غير المدعومة ترجع ناقصة مع إرشاد للتصحيح، ولا يعاد تفسير جزء منها كمبلغ. لا يدّعي هذا المحلل دعم العربية الحرة بكل تراكيبها؛ يظل الإدخال اليدوي والتأكيد الصريح ضروريين.

أضيفت 3 دوال اختبار انحدار تشمل هذه الحالات والآلاف اللفظية المتعددة. نجحت 45/45 دالة مضيفة محليًا بعد ضبط مجلد تشغيل اختبارات الموارد إلى app (كما تفعل مهمة Gradle للوحدة). لا تعديل في ملفات JUnit الحقيقية، والاختبارات المحلية ليست بوابة Android.

## فشل البناء الأول وسببه

Android CI #1254، run 35227619293، رأس d26577f6fe3cf48ff2b49806a5f18a9016bad3c9، توقف في إعداد SDK قبل Gradle: `Failed to find package 'tools'`. ليست هذه نتيجة فشل اختبارات التطبيق، إذ لم تبدأ.

إجراء setup-android@v3 يطلب افتراضيًا `tools platform-tools`. حددت `packages: platform-tools` في CI وSigned Release، مع استمرار sdkmanager في تثبيت API 36 وbuild-tools 36.0.0. لم أعدّل إصدار المنصة أو المكتبات، ولم أتجاوز خطوة فاشلة أو أعطل اختبارًا. أوقفت طباعة نصوص الرخص المطولة فقط، لا قبولها الافتراضي.

مصدر عقد الإجراء: https://github.com/android-actions/setup-android/blob/v3/action.yml

صحح اسم artifact في Signed Release إلى 0.1.1؛ لم ينفذ نشر موقّع أو تعديل مفاتيح.
