# معالجة ملاحظة مراجعة PR #14 — Schema غير ملتزمة

المصدر: ملاحظة Codex الآلية بتاريخ 2026-09-17 على `.github/workflows/ci.yml`، thread `PRRT_kwDOT2xJZs6jYGve`، comment `4037429461` في PR #14.

الملاحظة صحيحة: `git diff --exit-code -- app/schemas/` لا يكتشف ملفًا جديدًا غير متتبع يولده KSP مثل `12.json` في ترقية مستقبلية؛ لذلك قد ينجح الفحص رغم عدم التزام schema الجديدة.

استبدل فحص النظافة بقراءة `git status --porcelain --untracked-files=all -- app/schemas/` والفشل عند أي نتيجة. يشمل الملف الجديد والتعديل والحذف والتعديلات المرحّلة، مع طباعة المسارات والفرق للتشخيص. بقيت فحوص v11 قبل الرفع بلا تعطيل، ولا تعديل في schema أو migrations نفسها.

اختبار إعادة إنتاج محلي في مستودع Git مؤقت منفصل، خمس حالات ناجحة:

1. Schema ملتزمة ونظيفة: قبول.
2. `12.json` جديدة غير متتبعة: رفض؛ ثبت أن أمر git diff السابق كان يمر في الحالة نفسها.
3. تعديل ملف ملتزم: رفض.
4. تعديل مرحّل في index: رفض.
5. حذف schema ملتزمة: رفض.

هذه فحوص shell إضافية، لا تضاف إلى عدد اختبارات JUnit البالغ 156 في بوابة #1255. يعاد تشغيل Android CI على رأس تعديل الفحص قبل الدمج، وتوثق النتيجة في سجل PR #14. الملاحظة مراجعة آلية وليست اعتماد مراجع بشري.
