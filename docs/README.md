# وثائق تنفيذ وَصل

- `CURRENT_STATUS.md` — الحالة الحية، آخر نقطة تحقق، والمراحل المتبقية.
- `PHASE_CLAIMS.md` — المرحلة A: ميزة «طالبني» ومعايير القبول والهجرة والاختبارات.
- `../HANDOFF.md` — تسليم هندسي تاريخي؛ يجب تحديثه عند اعتماد رأس جديد بعد CI.
- `../WASL_MASTER_PROJECT_PROMPT.md` — المرجع التأسيسي الأعلى للمنتج.
- `../DECISIONS.md` — القرارات المعمارية والتقنية طويلة المدى.
- `../CHANGELOG.md` — سجل التغييرات المنفذة.

عند اختلاف وثيقة تنفيذية قديمة مع المواصفة التأسيسية، تكون الأولوية للمواصفة الأساسية ثم للحالة الحية الموثقة حديثًا، مع تحديث الوثيقة القديمة بدل ترك تعارض صامت.
