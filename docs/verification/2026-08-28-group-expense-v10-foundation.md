# Group Expense v10 Foundation — Verification Gate

Date: 2026-08-28

## Scope

This gate covers the data/domain foundation for shared expenses or group debts. It intentionally does not add the final Group Expense UI yet.

- `GroupExpense` is the immutable original group operation.
- Each share creates and links to an ordinary Wasl Debt, so the existing Ledger remains the financial source of truth.
- Unequal shares are supported when all shares use one currency and sum exactly to the group total.
- Creation is atomic inside one Room transaction.
- Replay by command ID is idempotent; conflicting replay is rejected.
- Missing/archived participants or conflicting IDs roll back the entire operation.
- Room database is upgraded from v9 to v10 with `group_expenses` and `group_expense_shares`.
- Encrypted Backup/Restore v10 includes both group tables and validates group/share relationships and financial invariants.
- Restore also rejects malformed group IDs, command IDs, currency metadata, blank notes, invalid share references, and invalid share sequence metadata before mutating live data.

## Tests added

- Domain invariants for unequal shares, exact total matching, currency consistency, and duplicate person/debt rejection.
- Migration 9→10 preserving existing debt data and verifying new indexes.
- Repository atomic creation, idempotent replay, conflicting replay rejection, and rollback on a missing participant.
- Encrypted backup/restore of the original group operation plus its generated ordinary debts.
- Malformed encrypted backup metadata rejection before live-data mutation.
